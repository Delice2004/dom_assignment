 Discover Rwanda – Land of a Thousand Hills


Discover Rwanda is a responsive tourism website that showcases the beauty of Rwanda, including famous destinations, activities, and cultural experiences. It allows users to explore places, interact with dynamic features, and build a personal travel bucket list.

Features Implemented
- Dark mode and Light mode toggle
- Responsive navigation bar (desktop and mobile)
- Dropdown menu for destinations
- Destination cards (Volcanoes, Lake Kivu, Kigali, Nyungwe)
- Interactive activity bucket list (add/remove items)
- Search functionality for list items
- Contact section with personalized greeting
- Scroll reveal animations
- Fully responsive design for all devices



This project demonstrates skills in:
- HTML structure and semantic layout
- CSS styling and responsive design techniques
- JavaScript DOM manipulation
- Event handling and user interaction
- Building interactive and responsive web applications
